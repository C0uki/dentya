# デン鉄 -DENTYA- 日本一周すごろく

桃太郎電鉄シリーズの構成要素をまとめた [`docs/game_elements_momotetsu_10x100.md`](docs/game_elements_momotetsu_10x100.md) をもとに作った、ブラウザで遊べる桃鉄風すごろくゲームです。

**依存ライブラリなし・1ファイル完結。** `index.html` をブラウザで開くだけで遊べます。

```bash
# ローカルで開く
open index.html          # macOS
# もしくは
python3 -m http.server   # → http://localhost:8000
```

## あそびかた

- サイコロを振って日本列島の路線を進み、**目的地に一番乗り**すると賞金がもらえます。
- 駅(全国99都市・全235マス)では**ご当地物件**を購入。街の物件をぜんぶ買うと**独占**で収益2倍。
- 毎年3月は**決算**。物件収益(価格×収益率)が入り、持ち金がマイナスだと利子10%。
- 目的地到着時にビリだったプレイヤーには**貧乏神**が憑依。放っておくと**キングボンビー**に変身して物件を破壊してくる…!同じマスの相手になすりつけよう。
- 設定した年数(1〜10年)が終わったとき、**総資産**(持ち金+物件)が一番多い人の勝ち。

| 元MDの大要素 | 実装内容 |

| 7. ビジュアル・演出 | 駅名標風の駅表示、カメラ追従、決算・独占・ボンビー登場・順位発表の演出 |

## 技術メモ

- HTML + CSS + Vanilla JS(1ファイル)。外部リソースへのリクエストは一切なし。
- マップは SVG。都市は実際の緯度経度から座標を投影し、簡略化した海岸線ポリゴンで日本列島を描画。過密地帯(関東・関西)は駅名標が重ならないよう自動で押し広げています。
- 都市間の中間マスは固定シードの乱数で生成するため、毎回同じ盤面になります。
- カメラは現在手番のプレイヤーを中心に拡大表示(＋/−ボタンでズーム調整、全体図に切替可)。
- 経路探索(CPU の進路選択・目的地までの距離表示)は BFS。
- 効果音は WebAudio API でその場で合成しています。
