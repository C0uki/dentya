# デン鉄 -DENTYA- 日本一周すごろく

桃太郎電鉄シリーズの構成要素をまとめた [`docs/game_elements_momotetsu_10x100.md`](docs/game_elements_momotetsu_10x100.md) をもとに作った、ブラウザで遊べる桃鉄風すごろくゲームです。『桃太郎電鉄 〜昭和 平成 令和も定番!〜』の紹介まとめを参考に、初心者向けの「あそびかた」画面や貧乏神ファミリー(ポコン・ビッグボンビー・デストロイ号)、歴史ヒーロー・名産怪獣イベントも収録しています。

**TypeScript + Vite製。** ソースは `src/` 以下にモジュール分割されています。

```bash
npm install
npm run dev      # 開発サーバー(http://localhost:5173)
npm run build    # 型チェック+本番ビルド(dist/ に出力)
npm run preview  # ビルド結果をローカルで確認
```

## あそびかた

- キミは鉄道会社の社長!サイコロを振って日本列島の路線を進み、**目的地に一番乗り**すると**援助金**がもらえます。
- 駅(全国99都市・全235マス)では**ご当地物件**を購入。街の物件をぜんぶ買うと**独占**で収益2倍。
- 毎年3月は**決算**。物件収益(価格×収益率)が入り、持ち金がマイナスだと利子10%。
- 目的地到着時にビリだったプレイヤーには**貧乏神**が憑依。放っておくと変身して大あばれ…!同じマスの相手になすりつけよう。
  - **キングボンビー**: 物件破壊や豪遊で大損害。終盤はさらに**デストロイ号**へ変身することも
  - **キングボンビーJr. ポコン**: 物件を吹き飛ばす!飛ばされた物件は近くの駅に落ちていて、通った人が**タダで拾える**
  - **ビッグボンビー**: サイコロを振って出た目のぶん**借金がふくらむ**
- ときどき駅で**歴史ヒーロー**(クラーク博士・伊達政宗・坂本龍馬など6人)や**名産怪獣**(リンゴリラ・ウドンガーなど5体)に出会えます。
- 設定した年数(1〜10年)が終わったとき、**総資産**(持ち金+物件)が一番多い人の勝ち。
- 初めての人はタイトル画面かゲーム中HUDの「?」から**あそびかた**(4ステップ+用語ガイド)を読めます。

## 技術メモ

- **TypeScript(strict)+ Vite**。フレームワークは使わず、DOM/SVG APIを直接操作するVanilla構成です。ビルドは `tsc --noEmit`(型チェック)→`vite build`(バンドル)の2段階。
- ソース構成(`src/`):
  | ファイル | 役割 |
  |---|---|
  | `types.ts` | 都市・駅・カード・プレイヤー・ゲーム状態などの型定義 |
  | `data.ts` | 都市99件・路線・海岸線・カード・貧乏神ラベルなどの静的データ |
  | `geo.ts` | 座標投影、路線グラフ構築、BFS距離計算 |
  | `state.ts` | ゲーム状態(`S`)とお金まわりの計算ヘルパー |
  | `sound.ts` | WebAudioによる効果音合成 |
  | `input.ts` | 手番アクション(サイコロ/カード使用)の待受 |
  | `render.ts` | SVG描画(地図・コマ・カメラ・目的地矢印) |
  | `ui.ts` | DOM操作(HUD・ランキング・モーダル・あそびかた画面) |
  | `game.ts` | ターン進行・決算・貧乏神・カード効果などのゲームロジック |
  | `main.ts` | エントリーポイント。各モジュールを配線して起動 |
- マップは SVG。都市は実際の緯度経度から座標を投影し、簡略化した海岸線ポリゴンで日本列島を描画。過密地帯(関東・関西)は駅名標が重ならないよう自動で押し広げています。
- 立体表現は 2.5D 方式:描画時に Y 軸を圧縮した俯瞰投影にし、陸地・駅名標・マスに側面(厚み)を描き、南側の要素が手前にかぶさるよう Y 座標順に描画。コマは影つきの立ち姿、サイコロは CSS 3D の回転キューブです。WebGL 不使用なので軽量です。
- 都市間の中間マスは固定シードの乱数で生成するため、毎回同じ盤面になります。
- カメラは現在手番のプレイヤーを中心に拡大表示(＋/−ボタンでズーム調整、全体図に切替可)。
- 経路探索(CPU の進路選択・目的地までの距離表示)は BFS。
- 効果音は WebAudio API でその場で合成しています。
- 外部リソースへのリクエストは一切なし(Vercel Speed Insightsのスクリプトを除く)。
